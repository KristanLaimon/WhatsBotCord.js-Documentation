All contributions are welcomed!

## Setting Up Development Environment

* **Bun.js** (version `1.2.20` or greater) is used as the testing framework and primary runtime for this project.

### Running Tests

To run all tests (skipping the long time-consuming ones):

```shell
bun fastest
```

To run the full test suite:

```shell
bun fulltest
```

## Submitting a Pull Request

1. Create a branch for your changes: `git checkout -b feature/your-feature`.
2. Commit your changes with clear messages.
3. Push to your fork.
4. Submit a pull request to the main repository.

## Reporting Bugs

Open a GitHub issue on the Issues page with a detailed description of the bug.\
Please include:

* Steps to reproduce
* Expected behavior
* Actual behavior
